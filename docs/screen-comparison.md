# 画面比較の記録（S01〜S34）

2026-10-15。参照は docs/ui-reference/screens の PNG（Penpot 書き出し、1440×940、ローカル専用）と同じ ID の配置JSON。実装画面は e2e/screens.capture.ts で同じ状態（架空マスター・架空データ・2026-10-14 09:00 JST 固定）を作り、1440×940・グレースケール描画（`--disable-lcd-text`）で撮影した。

- 再現：`npm run screens:capture` → `npm run screens:compare -- app`（work/screens/compare/app に並列画像・差分画像・report.json）。
- 差分率は pixelmatch（しきい値 0.1）の不一致画素の割合。位置合わせは scripts/extents.mjs（文字の外接矩形）と縦横の色境界の計測で、主要な文字・枠を参照と ±1px 以内に揃えた（下表の「残る差」を除く）。
- 共通の差：①フッターは設計の注記（「画面設計 v1 • 数値・装備条件は説明用のサンプルです」）の代わりにアプリ版・マスター版を表示、②設計上の注記（「（架空の例）」「（画像表示例）」など）は表示しない、③濃い背景上の白文字は参照より太く描画される（描画エンジンの差。CSS では一致させられない）。
- 参照PNGは Git 対象外。並列画像・差分画像も work/ に置き、公開しない。
