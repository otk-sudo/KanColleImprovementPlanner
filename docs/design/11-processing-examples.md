2026-10-14。以下はすべて架空の装備・費用による設計例。テストは未実行。Claudeは09/10の処理を実装した後に自動テストへ落とす。

## 手で追う小さな例

X★6を3個残したい。所持はX★6が1個、X★5が2個。★5→6の費用をネジ4、素材Y1と仮定。Yは1個、ネジは6個、1日1回、両工程は毎日実施可能とする。

| 段階 | 装備の扱い | ネジ・素材 |
|---|---|---|
| 完成品確保 | X★6を1個保護 | 変化なし |
| 対象確保 | X★5を2個作業対象にする | 変化なし |
| 必要数 | 工程A、Bを各1回 | ネジ8、Y2 |
| 在庫照合 | 対象を素材へ回さない | ネジ不足2、Y不足1 |
| 今日A | 通常予定 | 仮想残ネジ2、Y0 |
| 明日B | 仮配置 | 仮想残ネジ−2、Y−1。不足2/1 |
| 今日未実施 | Aを今日に保持 | 実在庫6/1のまま |
| 翌日起動 | Aを今日、Bを翌日へ | A/Bの重複作成なし |

計画の仮想残数と実在庫は別。予定を作っただけでネジ6を減らさない。

## 変えてはいけない不変条件

- 実在庫を計画作成・取消・スキップで変更しない。
- 同じ個体/数量枠は同時に複数の用途へ割り当てない。
- 計画出力の消費先は出力工程より後。日付同一なら順序を比較する。
- 1試行の有効結果は1つ。同工程の有効な未実施次回試行は種別を問わず最大1つ（activeNextAttemptByStep）。
- 派生計画の入力版本は現データと一致するか、古いと表示する。
- 不明な在庫・費用を0として合計完了しない。既知部分合計と未確定項目を併記する。
