# 実出典の計画を手で追う例（A04）

R09〜R12、A04。2026-10-17、EquipmentUpgradesの固定コミット `1a72dff0ec6658e09730335895af5f404ff76d22` とstart2の固定版を使用。元の費用を読み、以下の加算・乗算で期待値を求めた。所持は試験用の合成値であり、実ゲームでの実施・失敗消費・配布許諾を証明しない。

## 元の値

- ID1の1回の資源は燃料10・弾薬20・鋼材40。到達★1〜6は釘2/2・ネジ1/2・同装備1個、★7〜10は釘2/3・ネジ1/2・同装備2個（通常/確実化）。
- ID121は毎回鋼材80・ボーキ70。エントリ0の★7〜10は釘4/6・ネジ3/5・ID3を1個、ID122への更新は釘8/10・ネジ5/10・ID3を2個。
- ID121のエントリ1の★7〜10は釘4/6・ネジ3/5・ID10を1個、ID130への更新は釘7/9・ネジ5/9・ID10を2個。
